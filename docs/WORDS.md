# Tawazon Plus — words guide (English · العربية)

How Tawazon talks. Every screen uses these exact terms, so a person never has to
wonder whether two words mean the same thing.

## Voice

- **A kind older sibling who is good with money.** Warm, calm, never preachy.
- **Short sentences.** One idea per sentence. Most sentences under 12 words.
- **Say what happens, with the real number.** "Your daily number goes up to 215 SAR", not "Your balance was updated".
- **No guilt, no alarm.** Problems are "Let's look at it together". Never "Error", "Overspent", "Warning".
- **Praise small wins.** "Nice! One more payment done."
- **Buttons say the action.** "Save", "Start saving for it", "Mark as received" — never "OK" / "Submit".
- English: sentence case everywhere ("My money", not "My Money"). Contractions are fine ("you're", "don't").
- Arabic: clear Modern Standard Arabic with a light, friendly Saudi touch. Address the user as «أنت».
  Friendly words that everyone uses are welcome: «تقدر»، «فلوس»، «مصروف». Avoid heavy dialect:
  «اللي ← الذي/التي»، «عشان ← لأن/حتى»، «شوي ← قليلًا»، «وش ← ماذا»، «كذا ← هكذا»، «زي ← مثل»، «ما في ← لا يوجد».

## Never use

commitments · liabilities · cycle · available · budget deficit · transaction
التزامات · متاح/متاحة · دورة · الخصوم · عجز · معاملة

## Numbers

- Always show the currency with the number: "200 SAR" / "200 ر.س".
- Show a change as "200 → 215" (Arabic reads «200 ← 215» naturally right to left).
- Round to whole riyals. "About" only when the number really is an estimate.
